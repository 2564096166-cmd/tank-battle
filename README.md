# 🛡️ 坦克大战 (Battle City)

一个用原生 HTML + Canvas + JavaScript 实现的经典坦克大战游戏,单文件、零依赖,打开即玩。

## ✨ 特性

- 🎮 经典「坦克大战」玩法:守住基地老鹰,消灭所有敌方坦克
- 🧱 可破坏的砖墙、不可破坏的钢墙、水域与草丛地形
- 🏆 3 个关卡,分数 / 生命 / 剩余敌人数 HUD 显示
- ⭐ 道具系统:星星(强化双发·穿透钢墙)、生命加成
- 🔊 基于 Web Audio 的复古 8-bit 音效
- 💥 粒子爆炸、屏幕震动、出生保护等视觉反馈
- 📱 纯键盘操作,无需任何外部库

## 🎯 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或 `↑` `←` `↓` `→` | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `回车` | 开始 / 重新开始 |

## 🚀 运行

直接用浏览器打开 `index.html` 即可,无需服务器。也可以本地起一个静态服务:

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🕹️ 玩法说明

- 守住屏幕底部的**老鹰基地**,一旦被击毁立即失败
- 消灭当前关卡所有敌方坦克即可过关(共 3 关)
- 红色坦克是**强化坦克**(价值 500 分),击毁后可能掉落道具
- 击败普通坦克得 100 分,捡到「★」可让子弹穿透钢墙
